四、D1：固定原划分，只改变训练随机性

任务矩阵：5 配置 × 10 个共同新训练 seed＝50 个任务。
保持原数据版本、节点划分、模型、训练配方、早停和候选评分机制。不要在这一组同时引入独立早停节点或固定 epoch。

新 seed 必须与原 0／1／2 不同，并且这 5 配置在该精确协议下尚未有已评分结果。按身份／清单检查，不能查看得分挑 seed。
默认从 100 开始按整数递增，确定性排除已有对应评分记录的 seed，取前 10 个可用值；5 配置共享同一列表，冻结后不得替换。
每项从随机初始化训练，不能继承原最佳 checkpoint 的权重。共同 seed 是配对实验设计，不表示不同配置误差完全独立。

每个任务保存：
- dataset／recipe／mask／config／seed 的完整身份和 hash。
- best epoch、early-stop 分数、候选 selection 分数、停止原因。
- 恢复后的 checkpoint、hash、训练日志和实际成本。
- 若现有入口支持，保存 selection 节点 logits／逐节点正确性，供固定分析复算。

这里先不计算新 checkpoint 的旧 test。完成封存后，在 D4 统一读取。
不要把 50 个模型当成 50 个独立数据集，也不要将某配置最佳 seed 当成主要结果。

五、D2：仅改变开发节点划分

任务矩阵：5 配置 × 5 个冻结开发划分 × 每划分 3 个共同训练 seed＝75 个任务。
除节点划分外，训练配方、早停语义、评分语义和 checkpoint 规则与 D1 一致。
若原来同一验证 mask 同时用于早停和评分，本轮继续保留这一语义以隔离划分因素；记录这个问题，拆分两种用途的效果需要后续消融。

开发标签池只能来自原协议已允许用于开发的节点；通常是原 train 与 validation／early-stop 的并集。必须明确权限并断言与原 test 集不相交。
旧 test 标签不能用于分层抽样、训练、早停、配置评分、阈值设置或规则选择。
原 transductive 协议允许时，可以保留全图结构和无标签特征；不能因此读取旧 test 标签参与开发。

划分生成的默认规则：
1. 对允许的开发标签池做分层随机分配，保持原每类 train 标签数量和各评分角色的节点规模。
2. 原 early-stop 与 selection 分离时，新划分保留分离及原各角色的每类数量；原二者相同时，保留共用。
3. 只用开发池标签生成划分；所有配置共享完全相同的 masks。
4. 默认使用 split_seed 2026100701 至 2026100705；训练 seed 使用 D1 已冻结列表的前 3 个，在每个新 mask 下共同使用。这样可与原 mask 下同 3 个 seed 的结果配对，避免同时换 mask 和 seed。
5. 如果仅按身份检查发现生成 mask 与原 mask 或其他新 mask 完全相同，用确定性递增的后续 split_seed 替代，全部在新成绩产生前完成并冻结。
6. 记录抽样工具、随机数实现、节点排序、集合 hash、类别配额与不同划分重叠程度。

在旧 Cora public 等固定划分任务中，单独修改 --split_seed 可能根本不会改变 masks。必须显式传入冻结节点索引，并在训练进程验证实际生效的 hash。
这些是新的开发划分实验，不能把它们的准确率直接当作原 public 划分的同协议成绩。
若标签权限、类别数或可用节点不足以生成可解释的划分，完成可做的 D0／D1，D2 标记受阻并交付具体限制。不得借用 test 标签、减少配额后隐藏协议变化，或自动换数据集训练。

D2 保存与 D1 相同的任务记录，但不计算旧 test；本轮 D2 的 test 评分次数为 0。
本轮没有自动验证早停节点分离、固定 epoch 或多划分 GP 目标的收益。

六、D3：工程验证、预算与续跑

最低限度的有效检查：
1. 完整配置重建一致；模型能实际加载并使用对应架构和 HP。
2. 开发与 test 集合不相交；训练／早停／评分实际使用的 masks 与 manifest hash 一致。
3. train 与评分逻辑不访问旧 test 标签；仅 D4 的独立最终评分入口获准访问。
4. 最佳状态确实恢复；统计成绩对应恢复后的 checkpoint。
5. 缓存键包含完整配置、数据版本、全部 masks、训练配方、早停／评分语义、seed 和 checkpoint 规则。
6. 原 528 次缓存不会被误认为新 mask／新 seed 的结果。允许恢复本轮相同完整身份的已完成任务。
7. 真实中断恢复能继续剩余任务，已完成结果不新增训练、不重评分，结果 hash 和指标不变。

先用静态验证和小型合成检查测试数据边界、缓存身份、checkpoint 恢复及续跑。真实 GNN 试跑必须取自冻结的 125 个任务，并计入预算。
不为检查而额外运行全池训练、搜索或 GP 拟合。

预算规则：
- 正常完整执行新增 125 个从初始化训练的任务：D1 50、D2 75。
- 从随机初始化的失败重启也计入总训练启动次数；总计不得突破 125 次。
- 从同一任务的完整最新训练状态继续训练须恢复模型、优化器、调度器、RNG、epoch 和早停计数，单独记录续跑及累计 GPU 时间，不重复计为新初始化。仅加载 best 权重后重新训练不算严格续跑，计作新训练启动，且不能混作原流程的等价恢复。
- 失败、OOM、NaN、超时都保留日志，不能删掉失败任务、换 seed 或只报告成功样本。
- 若失败占用预算导致矩阵不完整，报告实际完成／失败／未执行数；不能超预算补到显著。
- 只允许修复已定位的任务实现问题；若修复改变了原训练配方或科学目标，停止受影响组，报告版本断点，不混合成绩。
- 冻结后，不按中途显著性或结果方向提前结束或追加样本。

运行时复用项目已有调度方式，先查可用 GPU 和当前占用，合理设置并发，不中断其他用户任务。
分别记录计划任务数、训练启动数、成功数、失败数、恢复数、旧 test 前向评分数、GPU 时间及墙钟。
若 D2 受阻，D1 可以在自身输入和数据边界明确时完成；终态必须注明诊断不完整。

七、D4：封存后统一旧 test 诊断与统计

在 D1／D2 的协议、候选和分析规则全部冻结，且 D1 训练已完成后：
1. 封存 D1 全部成功任务的配置、seed、best epoch、checkpoint 和 hash。
2. 独立评分脚本对这些 checkpoint 统一评价原 test；正常为 50 次 checkpoint 前向评分，不新增 GNN 训练。
3. 不重新按 test 选择 epoch、seed、配置或候选名单。
4. 原 test 已用于发现问题，本次只能称“旧任务上的重复诊断”，不能称新的独立 test 确认。
5. D2 的 test 标签继续隔离。若 D2 不完整，也不能因此更改已冻结的 D1 比较。

统计方法在新成绩出现前固定：
   如有失败或缺失，每项配置比较只用双方均完成的相同 seed 配对，并明确各组实际配对数；D2 逐划分也按此规则处理。不填补成绩，不把不同 seed 子集的均值作配对。缺失可能依赖配置时，报告偏差风险，结果限于描述，不能把完整样本推断照搬到剩余样本。
A. D1：以 10 组共同新 seed 为配对单位。
   对每配置给出 selection 均值、标准差、诊断 test 均值、标准差和逐 seed 表。
   主要给出 C0−C1 的 selection 与旧 test 配对差值，单位统一为百分点。
   给出均值／中位数、胜平负、95% 配对区间，以及每 seed 的验证／test 排名是否反转。
   区间默认用配对 seed bootstrap，10,000 次，固定分析 RNG seed 20261007；每次整体抽取 seed，保留配置间配对。
   报告新 seed 均值排名是否复现原 3 seed 的反转，不能只报告个别反转的 seed。
   C0 对其他配置属于补充分析；如做多个正式显著性检验，明确 Holm 等预先固定的多重比较规则。
   区间包含 0 表示证据不足，不能据此断言没有差异；10 个 seed 的小样本限制需明确。

B. D2：先在每划分内平均 3 个 seed，再分析 5 个划分。
   给出各配置每划分的均值、seed 标准差、排名及第一名身份。
   给出 C0−C1 及 C0 对其余配置的逐划分差值、正负变化、冠军变化频率和划分间波动。
   可以给出按划分整体重采样的探索性区间，但注明只有 5 个划分、同图且 masks 重叠，不是跨数据集泛化区间。
   不把 15 个 split×seed 数值当成 15 份独立划分证据，也不把 75 次训练当成 75 个独立任务。
   不将不同 mask 的平均准确率变化全部归因于配置；优先比较同 mask 下配置之间的配对差。
   若与原 mask 比较，使用 D1 中相同 3 个 seed 的子集作配对参照；不能直接把 D1 的 10 seed 均值与 D2 的 3 seed 均值之差全部解释成划分影响。

C. 噪声和划分机制的描述性比较：
   将原 C0−C1 验证差距，与 D1 中配对差的 seed 波动及“原 3 seed 均值估计”的近似不确定性对照。
   区分 D2 各划分内的 seed 波动与不同划分的均值差异；可以报告方差描述，但不要凭 5 个划分宣称已精确分解因果贡献。
   明确共同 seed 的相关性、同图节点相关性、固定验证集选优和最佳 epoch 选择仍可能影响结果。
   不要求必须将失败归因于单一机制；“训练与划分因素共同敏感”或“现有证据仍不足”都是有效终态。

D. 固定输出图表：
   D1 配对差分布／均值区间；D2 配置×划分成绩与排名图；验证／旧 test 的配置均值对照。
   所有点、失败和完整配对表保留，禁止只挑最好配置／seed／划分作图。

八、依据结果形成下一阶段建议，不自动执行

请用“证据 → 能支持的解释 → 下一步候选修改 → 仍需确认什么”给出建议：
1. 固定划分的排名随 seed 变化，且候选差距与均值估计噪声相当：优先研究共同新 seed 的终局 top-k 复评。
2. 配对差和排名随开发划分变化明显，超过划分内训练波动所能解释的直观范围：优先研究多开发划分复评；增加 seed 不能消除固定节点偏好。
