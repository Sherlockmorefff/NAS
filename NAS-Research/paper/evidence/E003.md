# 四数据集历史 search 矩阵

## 1. 研究问题

S0/G100/G150 的 300-full search-validation、surrogate diagnostics、invalid rate 与运行成本是否在 CiteSeer、PubMed、DBLP、Flickr 和 search seeds 5–9 上呈现一致关系？此证据不含 final test。

## 2. 实验状态

- 历史 search：完整完成。4 datasets × 3 methods × 5 search seeds = 60/60；每个 history 300 条 full-evaluation 记录。
- 记录完整性：18,000 条中 3 条 invalid，run 仍以 `fixed_iteration_complete` 结束。
- 匹配 final evaluation：无法确认/缺失，0/60。
- 当前 HEAD 重跑：与历史完成分开。CiteSeer/PubMed/DBLP 的 GPU 资源预检已通过但 authorization seed 范围冲突；Flickr formal seeds 最新预检及 retry OOM。

## 3. 实验协议

| 项目 | 已核实设置 |
| --- | --- |
| datasets | CiteSeer、PubMed（Planetoid public split）；DBLP deterministic constructed split；Flickr official masks |
| methods | S0/global Schur、G100、G150 |
| search seeds | 5–9 |
| full budgets | 全方法 300；50+250、50+100+150、50+150+100 |
| LF cost | G100/G150 每 seed 实际 LF candidates 360/311/338/259/400，20 epochs；34.53–53.33 equivalent-full，均值 44.48 |
| search training | 150 epochs、patience 40 |
| surrogate/acquisition | scratch Exact GP、fixed-domain normalization、qLogEI |
| selection/evaluation | search validation accuracy；无匹配 final-test artifact |
| controls | 同 dataset/search seed 内共享候选域和 full budget；LF 总成本不同 |

## 4. 已核实结果

项目级完整数值在 [`../../results/tables.md`](../../results/tables.md)。本卡登记 Claim 相关结论：

- 5-search-seed search-validation mean：CiteSeer S0/G100/G150 `.72920/.72400/.71400`；PubMed `.82040/.81280/.81480`；DBLP `.80680/.80320/.80080`；Flickr `.522257/.520375/.519747`。
- S0 的 mean 在四个数据集均最高，但多个 95% t-CI 重叠；这里只能描述 search validation。
- 最后记录窗口 surrogate 指标无一致支配。例如 CiteSeer/G100 的 MAE、coverage、Spearman 较 S0 好，而 PubMed/DBLP 多项由 S0 更好，Flickr 指标方向混合。
- 18,000 条 full records 中 3 条 invalid：CiteSeer/S0/seed5 step253、CiteSeer/G100/seed5 step214、DBLP/S0/seed9 step143。
- 历史 run-summary wall time 可用于 provenance 描述，但受硬件、并发与旧实现影响，不是跨硬件 benchmark。

## 6. 解释

- 直接表明：历史同协议 search 中没有 G100/G150 跨四数据集稳定高于 S0 的终点 validation 证据；surrogate 指标也没有统一支配关系；LF 具有额外成本。
- 合理但未证明：初始化效果依赖 dataset、目标噪声或搜索轨迹；某些 surrogate 指标改善未转化为终点 validation。
- Alternative explanations：5-seed power、旧 dirty-worktree runtime、invalid 记录、LF 成本和终点指标可能掩盖 early behavior。
- 不能推出：S0 在 final test 上普遍更优、clustered 方法无早期收益、当前 HEAD 已复现历史矩阵，或 Flickr 当前可重跑。
