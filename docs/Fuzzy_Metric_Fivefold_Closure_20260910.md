## 3. 主结果与固定收尾判定

“全体顺序”检查：对同一查询，性能差较小的参考是否也更近。“额外差距” $E=D_e-D_*$ 比较表示选来的5邻居与池内真实最接近5邻居；越小越好。最佳邻居只是事后参照，不代表有限标签模型必然能达到。

沿用前轮计分：性能差之差在 $10^{-12}$ 内的对排除；有效对同序1、逆序0、距离并列0.5。距离并列为 $10^{-10}s_q$，$s_q$ 取本折全部参考的最大距离，局部10也用该尺度。无有效对记NA，计分不按ID破并列；选择邻居则按原始值完全相同时用ID定序。
